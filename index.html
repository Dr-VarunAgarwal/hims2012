⚙️ Automated Online Data Collection (Google Sheets Webhook)

When batchmates submit their details online, the form posts directly to a Google Sheet via this simple Apps Script:

// Google Sheet -> Extensions -> Apps Script
function doPost(e) {
var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
var d = JSON.parse(e.postData.contents);
sheet.appendRow([new Date(), d.doctor_no, d.name, d.qualifications, d.working_at, d.city_based, d.phone, d.email, d.attendance_status, d.package, d.spouse_name, d.spouse_prof, d.total_amount, d.hoodie, d.utr]);
return ContentService.createTextOutput("Success");
}
